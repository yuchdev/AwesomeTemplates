# Language Specializations

For Python, create specializations agents and/or skills for expertise in: 

* Django
* Web scrapping
* ML/AI

For Java, create specializations agents and/or skills for expertise in: 

* Spring
* Android

Created agents and/or skills should be independent from python preset. In the next step they'd be listed in docs.

Update in CLI `generate` optional command to choose specialization. If omitted, generate core Python or Java.
